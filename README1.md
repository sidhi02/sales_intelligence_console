# 🛒 Sales Intelligence Console

## 📌 Project Description

Sales Intelligence Console is an enterprise-grade business intelligence and analytics platform designed to transform raw e-commerce data into actionable operational insights through forecasting, anomaly detection, customer intelligence, KPI monitoring, and AI-style recommendation systems.

The project combines Tableau-based business intelligence reporting with a fully interactive Streamlit analytics application to simulate a real-world enterprise intelligence ecosystem.

---

# 🚀 Project Ecosystem

This project consists of two separate analytical systems:

## 📊 Tableau Business Intelligence Dashboard

A dedicated Tableau dashboard built for:
- Executive KPI reporting
- Exploratory business analytics
- Interactive visual storytelling
- Regional and category-level analysis
- Revenue trend monitoring

---

## 🧠 Streamlit Sales Intelligence Application

A fully deployed enterprise analytics platform built for:
- Predictive forecasting
- Operational intelligence
- AI-style recommendations
- Customer segmentation
- Process deviation monitoring
- Interactive business analytics

Unlike traditional dashboards, the Streamlit platform functions as a modular business intelligence application.

# ⚙️ Installation & Setup

## Clone Repository

```bash
git clone https://github.com/sidhi02/sales-intelligence-console.git
```

---

## Move into Project Directory

```bash
cd sales-intelligence-console
```

---

## Install Dependencies

```bash
pip install -r requirements.txt
```

---

## Run Streamlit Application

```bash
streamlit run app.py
```
